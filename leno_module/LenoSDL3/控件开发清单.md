# LenoSDL3 GUI 控件开发清单

> 目标：在现有 `Button / Label / Edit / Dialog` 基础上，补齐一套可用的 GUI 控件库。
> 当前控件范式：`set(Dict)` 初始化 → `process(Event)` 交互 → `render(Renderer)` 绘制 → `dispose()` 释放。
> 每个控件一个 `sdl_xxx.leno` 文件 + 工厂 `createXxx(Dict)`。

---

## 第 0 步：统一控件注册机制（基础设施，必须先做）

**动机**：`Window.run()` 主循环目前硬编码只认 `Button/Label/Edit`，每加一个控件都要改 `sdl_window.leno` 三处。引入 `face Widget` 后，新控件只需 `win.add(widget)` 一行即可自动参与事件与渲染。

- [x] 新增 `sdl_widget.leno`，定义 `face Widget { process(Event); render(Renderer); dispose() }`
- [x] `Button` / `Edit` 加 `impl Widget`
- [x] `Label` 补 `process(Event)` 空实现并加 `impl Widget`
- [x] `sdl_window.leno`：`Array[Widget] _widgets` + `add(Widget): Widget`；`run()` 内用单一循环统一 process/render；并行数组 `_runBtns/_runLbls/_runEdts` 合并为 `_runWidgets`
- [x] `SDL3.leno` 导出 `Widget` 类型
- [x] 回归测试：现有 `test_button / test_edit / test_label` 仍能编译运行
