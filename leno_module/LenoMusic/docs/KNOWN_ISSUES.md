# 已知问题列表

本文档记录 miniaudio DLL 和 Leno 音频模块中的已知问题，供后续修复参考。

---

## 1. 噪声生成器 setType 问题

**状态:** ⚠️ 已禁用

**问题描述:**
调用 `ma_noise_set_type()` 切换噪声类型时，miniaudio 内部触发断言失败：
```
Assertion failed: 0, file miniaudio.h, line 68994
```

**影响范围:**
- `Noise.setType()` 方法已移除
- 无法在运行时切换噪声类型

**解决方案:**
- 如需切换噪声类型，需重新创建 Noise 对象

---

## 2. Leno 类型限制

**状态:** ⚠️ 已知限制

**问题描述:**
1. Leno 不支持 `double` 类型，需使用 `float`
2. Leno 不支持 `export const`，需使用 `export var`
3. Struct 实例化需使用 `new` 关键字

**影响范围:**
- 所有浮点参数必须使用 `float`
- 常量定义使用 `var` 而非 `const`

---

## 3. FFI 调用限制

**状态:** ⚠️ 已知限制

**问题描述:**
1. `ffi.call_float()` 不存在，需使用 `ffi.call_double()` + `_float()` 转换
2. 类型转换语法: `_float(value)` 而非 `(float)value`

**示例:**
```leno
// 错误
return ffi.call_float(ma, "func")

// 正确
return _float(ffi.call_double(ma, "func"))
```

---

## 4. Struct 方法调用

**状态:** ⚠️ 已知限制

**问题描述:**
Struct 方法定义时，如果方法名与全局函数冲突（如 `sleep`），可能导致调用异常。

**解决方案:**
- 避免使用与全局函数同名的方法名
- 使用 Leno 内置 `sleep()` 而非自定义 `delay()`

---

## 5. 音频格式限制

**状态:** ℹ️ 设计限制

**问题描述:**
当前 DLL 主要测试了 `FORMAT_F32` (32位浮点) 格式，其他格式可能存在问题。

**建议:**
- 优先使用 `FORMAT_F32` 格式
- 其他格式需要额外测试

---

## 6. 跨平台注意事项

**状态:** ℹ️ 待验证

**问题描述:**
DLL 当前仅在 Windows 上编译测试，其他平台（Linux/macOS）需要：
1. 重新编译 DLL
2. 验证路径分隔符
3. 验证音频后端

---

## 7. 内存管理

**状态:** ℹ️ 已知限制

**问题描述:**
部分 miniaudio 对象需要预分配堆内存（如 `ma_noise`），使用 `malloc` 分配，需要确保正确释放。

**当前实现:**
- 使用静态全局变量存储对象
- 不支持同时创建多个同类型对象

---

## 8. 音量控制精度

**状态:** ℹ️ 已知限制

**问题描述:**
`Sound.getVolume()` 返回的浮点数在打印时可能显示为科学计数法（如 `5.6e-315`），但实际值正确。

**原因:**
Leno 浮点数打印格式问题，不影响实际使用。
