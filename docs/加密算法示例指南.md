## Base64 编码/解码

**文件**: [`examples/base64/base64.leno`](../examples/base64/base64.leno)

纯 LenoC 实现的 Base64 编解码，展示位运算和字符串操作能力。

```leno
import "examples/base64/base64.leno"

func main() {
    var encoded = base64_encode("Hello, Leno!")
    print(encoded)  // SGVsbG8sIExlbm8h
    var decoded = base64_decode(encoded)
    print(decoded)  // Hello, Leno!
}
```

**特性**:
- 标准 Base64 编码表
- 完整的 Padding 处理（`=`）
- 支持中文 UTF-8 字节编码
- 包含合法性检查

## 哈希算法

### MD5

**文件**: [`examples/crypto/md5.leno`](../examples/crypto/md5.leno)

RFC 1321 标准实现，生成 128 位（16 字节）哈希值。

```leno
var hash = md5("abc")
print(hash)  // 900150983cd24fb0d6963f7d28e17f72
```

> **安全提示**: MD5 已不推荐用于安全场景（如密码存储、数字签名），仅作学习演示或校验和用途。

### SHA-1

**文件**: [`examples/crypto/sha1.leno`](../examples/crypto/sha1.leno)

FIPS 180-4 标准实现，生成 160 位（20 字节）哈希值。

```leno
var hash = sha1("abc")
print(hash)  // a9993e364706816aba3e25717850c26c9cd0d89d
```

> **安全提示**: SHA-1 已被证明存在碰撞攻击，不推荐用于新系统的安全场景。

### SHA-256

**文件**: [`examples/crypto/sha256.leno`](../examples/crypto/sha256.leno)

FIPS 180-4 标准实现，生成 256 位（32 字节）哈希值，目前仍被认为是安全的哈希算法。

```leno
var hash = sha256("abc")
print(hash)  // ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```

### HMAC-SHA256

**文件**: [`examples/crypto/hmac_sha256.leno`](../examples/crypto/hmac_sha256.leno)

RFC 2104 标准实现，基于 SHA-256 的消息认证码，用于验证消息的完整性和真实性。

```leno
var mac = hmac_sha256("secret_key", "message to authenticate")
print(mac)
```

**应用场景**: API 签名、JWT、OAuth 消息验证。

## 对称加密

### AES-128

**文件**: [`examples/crypto/aes128.leno`](../examples/crypto/aes128.leno)

FIPS-197 标准 AES-128 实现，包含完整的 SubBytes、ShiftRows、MixColumns、AddRoundKey 和密钥扩展。

```leno
var key = "0123456789abcdef"        // 16 字节密钥
var plaintext = "Hello, AES-128!"

var ciphertext = aes128_encrypt(key, plaintext)
print(ciphertext)  // hex 编码密文

var decrypted = aes128_decrypt(key, ciphertext)
print(decrypted)   // Hello, AES-128!
```

**特性**:
- ECB 模式 + PKCS7 填充
- 完整的 NIST 测试向量验证
- 支持任意长度字符串（自动分块）
- 中文 UTF-8 支持

### ChaCha20

**文件**: [`examples/crypto/chacha20.leno`](../examples/crypto/chacha20.leno)

Daniel J. Bernstein 设计的现代流加密算法，被广泛用于 TLS 1.3、WireGuard、SSH。

```leno
var key = "01234567890123456789012345678901"  // 32 字节
var nonce = "012345678901"                     // 12 字节
var text = "Hello, ChaCha20!"

var enc = chacha20_encrypt(key, 0, nonce, text)
var dec = chacha20_decrypt(key, 0, nonce, enc)
```

**特性**:
- 256 位密钥 + 96 位 nonce + 32 位计数器
- 20 轮 Quarter Round 混合
- 输出 hex 编码避免 null 字节截断
- 多块自动处理（每块 64 字节）

### RC4

**文件**: [`examples/crypto/rc4.leno`](../examples/crypto/rc4.leno)

经典流密码，加密和解密使用相同操作（密钥流 XOR）。

```leno
var encrypted = rc4("password", "Hello, LenoC!")
var decrypted = rc4("password", encrypted)
```

> **安全提示**: RC4 已不被推荐用于生产环境，仅作学习演示。

### TEA / XTEA

**文件**:
- [`examples/crypto/tea.leno`](../examples/crypto/tea.leno)
- [`examples/crypto/xtea.leno`](../examples/crypto/xtea.leno)

TEA (Tiny Encryption Algorithm) 是一种微型块加密算法，64 位数据块 + 128 位密钥，32 轮 Feistel 网络。

```leno
var key = "0123456789abcdef"
var text = "Hello, TEA!"

var enc = tea_encrypt(key, text)
var dec = tea_decrypt(key, enc)
```

XTEA 是 TEA 的改进版，修复了等价密钥问题，算法更简洁，推荐使用 XTEA 替代 TEA。

```leno
var enc = xtea_encrypt(key, text)
var dec = xtea_decrypt(key, enc)
```

**特性**:
- ECB 模式 + PKCS7 填充
- 密钥不足 16 字节自动空格填充
- Hex 编解码便捷接口
- 中文支持

## 非对称加密

### RSA

**文件**: [`examples/crypto/rsa.leno`](../examples/crypto/rsa.leno)

PKCS#1 v1.5 风格的 RSA 实现，包含密钥生成、加密、解密、签名和验签。

```leno
// 使用已知密钥
var key = new RSAKey()
key.n = 3233
key.e = 17
key.d = 2753

var ciphertext = rsa_encrypt(42, key)
var plaintext = rsa_decrypt(ciphertext, key)

// 签名验证
var signature = rsa_sign(42, key)
var verified = rsa_verify(signature, key)
```

**特性**:
- 快速模幂运算（平方-乘法算法）
- 扩展欧几里得算法求模逆元
- Miller-Rabin 素性测试
- 随机素数生成

> **安全提示**: 此实现仅用于学习演示，生产环境请使用经过审计的密码库。

## 密钥派生

### PBKDF2

**文件**: [`examples/crypto/pbkdf2.leno`](../examples/crypto/pbkdf2.leno)

RFC 2898 标准实现，基于 HMAC-SHA256 的密钥派生函数，通过加盐和多次迭代抵抗暴力破解。

```leno
var derived_key = pbkdf2_hmac_sha256("password", "salt", 100000, 32)
print(derived_key)  // 64 字符 hex 字符串
```

**参数说明**:
- `password`: 密码字符串
- `salt`: 盐字符串（随机唯一）
- `iterations`: 迭代次数（推荐 100000+）
- `dk_len`: 派生密钥长度（字节数）

**应用场景**: 密码存储、磁盘加密、Wi-Fi WPA2。

## 古典密码

### 凯撒密码

**文件**: [`examples/crypto/caesar.leno`](../examples/crypto/caesar.leno)

最古老的替换密码之一，将每个字母在字母表中偏移固定位置。

```leno
var encrypted = caesar_enc("Hello, World!", 3)
var decrypted = caesar_dec(encrypted, 3)

// ROT13（偏移13，加密即解密）
var rot = rot13("Hello, ROT13!")
```

**额外功能**:
- 暴力破译（枚举 26 种偏移）
- 基于频率分析的自动破译
- 仿射密码（Affine Cipher）实现

### 维吉尼亚密码

**文件**: [`examples/crypto/vigenere.leno`](../examples/crypto/vigenere.leno)

多表替换密码，使用关键词重复地对明文字母进行不同偏移的凯撒替换。

```leno
var encrypted = vigenere_enc("LEMON", "ATTACKATDAWN")
print(encrypted)  // LXFOPVEFRNHR
var decrypted = vigenere_dec("LEMON", encrypted)
```

**额外功能**:
- 重合指数（IC）计算
- Kasiski 测试猜测密钥长度
- 基于频率分析的自动破译

### 仿射密码

**文件**: [`examples/crypto/caesar.leno`](../examples/crypto/caesar.leno)（与凯撒密码同文件）

凯撒密码的推广，使用 `E(x) = (ax + b) mod 26`。

```leno
var encrypted = affine_encrypt("HELLO AFFINE", 5, 8)
var decrypted = affine_decrypt(encrypted, 5, 8)
```

| Base64 | 编码 | - | 字符串 | - |
| MD5 | 哈希 | - | 128 bit | 已淘汰 |

| AES-128 | 对称块加密 | 128 bit | 密文 | 安全 |
| ChaCha20 | 对称流加密 | 256 bit | 密文 | 安全 |

| 凯撒/维吉尼亚 | 古典替换 | - | 密文 | 已淘汰 |
| 仿射密码 | 古典替换 | a, b | 密文 | 已淘汰 |

## 位宽转换函数

LenoC 提供了一组固定位宽转换函数，在加密算法中用于模拟 C 语言的固定位宽环绕运算。这些函数是所有加密算法实现的基础工具。

| 函数 | 返回范围 | 用途 |
|------|---------|------|
| `_int32(x)` | -2147483648 ~ 2147483647 | 32 位有符号环绕（AES、TEA、MD5 等） |
| `_uint32(x)` | 0 ~ 4294967295 | 32 位无符号位运算（MD5、SHA、PBKDF2 等） |
| `_int64(x)` | -9223372036854775808 ~ 9223372036854775807 | 64 位有符号运算 |
| `_uint64(x)` | 0 ~ 18446744073709551615 | 64 位无符号位运算、FFI 交互 |
| `_uint8(x)` / `_byte(x)` | 0 ~ 255 | 字节操作、协议解析 |

**典型用法：**

```leno
// 32 位环绕加法（MD5、SHA 等哈希算法的核心操作）
_int32(a + b)                    // 加法结果截断到 32 位

// 32 位无符号位运算（避免算术右移的符号扩展）
_int32(_uint32(x) & _uint32(y))  // 无符号 AND
_int32(_uint32(x) ^ _uint32(y))  // 无符号 XOR

// 32 位循环左移（MD5、SHA 的核心旋转操作）
_int32(_uint32(x) << n | _uint32(x) >> (32 - n))

// 字节提取（ChaCha20、AES 的序列化/反序列化）
_byte(value)          // 最低字节
_byte(value >> 8)     // 次低字节
_byte(value >> 24)    // 最高字节
```

> **💡 为什么加密算法需要这些函数？**
>
> C 语言的 `uint32_t` 等类型天然支持环绕运算，而 LenoC 的 `int` 是任意精度大整数，运算结果不会溢出。`_int32()`/`_uint32()` 模拟了 C 语言的固定位宽行为，使得加密算法的 LenoC 实现与 C 参考实现行为一致。
