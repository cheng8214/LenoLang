# LenoC VM 编译优化级别对比报告

测试日期：2026-05-27
测试环境：Windows x64, MinGW GCC
测试文件：`examples/性能测试/全部测试.leno`（通过 `--pack` 打包为独立 exe 运行）

---

## 一、优化级别说明

| 级别 | 含义 |
|------|------|
| `-O3` | 最高优化，激进内联、循环向量化等，体积最大，可能引入边界问题 |
| `-O2` | 标准优化，最广泛验证的级别，稳定且高效 |
| `-Os` | 体积优化，牺牲性能换取最小体积 |
| `-Og` | 调试优化，保留调试信息的同时做基本优化 |

所有级别均搭配 `-s`（剥离符号表）使用。

---

## 二、体积对比

| 优化级别 | leno_vm.exe | 打包后 exe |
|----------|-------------|------------|
| `-O3 -s` | 832 KB | ~853 KB |
| `-O2 -s` | **614 KB** | **~637 KB** |
| `-Og -s` | 519 KB | ~542 KB |
| `-Os -s` | 422 KB | ~443 KB |

## 四、综合评分

以 `-O3` 性能为 100% 基准，综合各项测试估算相对性能：

| 级别 | 体积 | 相对性能 | 稳定性 | 综合评价 |
|------|------|----------|--------|----------|
| `-O3 -s` | 832 KB | 100% | 中（激进优化可能引发边界问题） | 追求极致性能 |
| `-O2 -s` | 614 KB | ~90% | **高（最广泛验证的级别）** | **推荐** |
| `-Og -s` | 519 KB | ~60% | 高 | 调试场景 |
| `-Os -s` | 422 KB | ~40% | 高 | 追求极致体积 |

---

## 五、结论

**最终选择：`-O2 -s`**

理由：
1. **稳定性**：`-O2` 是 GCC 经过最广泛测试验证的优化级别，不会出现 `-O3` 激进优化可能导致的边界 bug
2. **性能**：相比 `-O3` 仅损失约 10% 性能，但远优于 `-Og` 和 `-Os`
3. **体积**：614 KB 比 `-O3` 小 26%，在可接受范围内
4. **性价比**：体积缩小 26% 仅换 10% 性能损失，是最优的体积/性能平衡点
