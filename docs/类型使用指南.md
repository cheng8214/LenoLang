# LenoC 类型使用指南

## 快速口诀

| 场景 | 推荐                         | 口诀          |
| -- | -------------------------- | ----------- |
| 变量 | `var x = 值`                | "右边有值用 var" |
| 参数 | `int x` / `Array[int] arr` | "参数写清楚"     |
| 默认参数 | `int y = 10`               | "默认值放末尾"   |
| 返回 | `:int` / `:Array[int]`     | "返回要声明"     |

**⚠️ 重要：`var`** **含义完全不同！**

| 场景       | 写法              | 实际类型  | 说明                        |
| -------- | --------------- | ----- | ------------------------- |
| **变量声明** | `var x = 1`     | `int` | ✅ 根据右边推断为具体类型             |
| **函数参数** | `func f(var x)` | `any` | ⚠️ 参数 `var` 保持 `any`，不推断！ |
| **函数返回** | `func f()`      | `any` | 省略 `:type` 则返回 `any`      |

**关键区别**：

- 变量 `var` = **推断模式**：右边是什么，`var` 就是什么
- 参数 `var` = **动态模式**：永远是 `any`，不根据调用推断

```leno
var x = 1              // x 是 int（推断）
func test(var x) {     // x 是 any（不推断！）
    var y = x          // y 也是 any（因为 x 是 any）
}

test(1)                // 调用时 x 仍是 any，不会变成 int
test("hello")          // x 仍然是 any
```

## 1. 变量声明

### ✅ 推荐：使用 `var`，让编译器推断

**`var`** **的类型由右侧表达式精确决定：**

- 右侧是具体类型（如 `1`、`"hello"`） → `var` 就是那个类型
- 右侧是 `any`（如函数返回 `any`） → `var` 也是 `any`

```leno
var x = 1           // 推断为 int
var s = "hello"     // 推断为 string
var arr = [1,2,3]   // 推断为 Array[int]

func getAny():any { return 1 }
var y = getAny()    // y 是 any，不是 int！
```

### ⚠️  重要：变量类型不可改变

`var` 推断出的**类型是永久的**，之后不能改变：

```leno
var a = 1              // a 永久是 int 类型
a = 2                  // ✅ 可以，值改变，类型不变
a = "hello"            // ❌ 错误：无法将 string 赋值给 int

var arr = [1,2,3]      // arr 永久是 Array[int]
arr.add(4)             // ✅ 可以，修改数组内容
arr = "string"         // ❌ 错误：不能改变变量类型

var msg = "hi"
msg = "hello"          // ✅ 可以，string 类型不变
msg = 123              // ❌ 错误：类型不匹配
```

> **规则**：变量一旦声明，类型终身不变，只能赋同类型的值。

### int 类型说明

LenoC 的 `int` 采用**双层存储**设计：

- **int48**：值在 ±140 万亿（约 48 位）以内时，直接内联存储，零开销
- **BigInt（自动升级）**：超出 int48 范围时，自动切换到堆上 BigInt，支持任意精度

整个过程对用户透明——你只需要写 `int`，编译器自动处理存储和精度升级。

```leno
var a = 100                    // int48（内联存储，零开销）
var b = 100000000000000000000  // 超出范围，自动升级为 BigInt
print(type(a))                 // "int"
print(type(b))                 // "int"——外部统一，内部自动
```

### int/float 自动升级

`int` 可以自动升级为 `float`（安全提升），但不能降级：

```leno
float x = 42        // ✅ int → float，自动升级
int y = 3.14        // ❌ float → int，不允许降级

var arr = [1, 2.0]  // ✅ 推断为 Array[float]（int 升级为 float）
arr.add(3)          // ✅ int 可以添加到 Array[float]
arr.add(3.14)       // ✅ float 也可以添加
```

**升级规则**：

- `int` → `float`：✅ 自动升级
- 反之（降级）：❌ 不允许，需要显式转换

### ⚠️  数组类型推断规则

| 数组形式                 | 推断类型         | 说明          |
| -------------------- | ------------ | ----------- |
| `[]`                 | `Array`      | 空数组，元素类型未指定 |
| `[1, 2, 3]`          | `Array[int]` | 同类型元素数组     |
| `[1, "hello", true]` | `Array[any]` | 混合类型数组      |

```leno
// 空数组：类型为 Array（未指定）
var arr = []
print(type(arr))    // "Array"
arr.add(1)          // 添加 int 后变为 Array[int]
print(type(arr))    // "Array[int]"
arr.add("hello")    // ❌ 错误：期望 int，传入 string

// 混合类型数组：类型为 Array[any]
var mixed = [1, "hello", true]
print(type(mixed))  // "Array[any]"
mixed.add(42)       // ✅ 可以添加 int
mixed.add("world")  // ✅ 可以添加 string
print(type(mixed))  // "Array[any]"（保持 any 类型）
```

**重要区别**：

- `Array`（空数组）：添加第一个元素后**更新**为具体类型
- `Array[any]`（混合数组）：保持 `any` 类型，**可以添加任何类型**

**建议**：尽量初始化时就明确元素类型：

```leno
var arr = [1,2,3]   // ✅ 明确为 Array[int]

// 或者直接声明空数组类型
Array[int] arr      // ✅ 空的 Array[int]
Array[int] arr2 = []   // ✅ 等同于上面
```

### 📋 数组类型检查覆盖

所有**修改**数组元素的操作都会进行类型检查：

| 操作       | 示例                 | 类型检查     |
| -------- | ------------------ | -------- |
| `add`    | `arr.add(1)`       | ✅ 检查元素类型 |
| `insert` | `arr.insert(0, 1)` | ✅ 检查元素类型 |
| 索引赋值     | `arr[0] = 1`       | ✅ 检查元素类型 |

```leno
var arr = []
arr.add(1)           // ✅ 类型变为 Array[int]
arr.insert(0, 2)     // ✅ 正确
arr[0] = 3           // ✅ 正确
arr.add("bad")       // ❌ 报错：期望 int
arr[0] = "bad"       // ❌ 报错：期望 int
```

**只读操作**（如 `len()`, `pop()`, `remove()`, `has()`, `copy()`）不影响类型检查。

### ⚠️  字典类型推断规则

字典类型推断规则与数组**完全一致**。字典的键可以是 `string` 或 `int`：

| 字典形式 | 推断类型 | 说明 |
| -------- | -------- | ---- |
| `{}` | `Dict` | 空字典，键/值类型未指定 |
| `{"a": 1, "b": 2}` | `Dict[string, int]` | 字符串键，同类型值 |
| `{"a": 1, "b": "hello"}` | `Dict[string, any]` | 字符串键，混合类型值 |
| `{1: "one", 2: "two"}` | `Dict[int, string]` | 整数键，同类型值 |
| `{1: 100, "a": 200}` | `Dict[any, int]` | 混合键，同类型值 |

```leno
// 空字典：类型为 Dict（未指定）
var dict = {}
print(type(dict))    // "Dict"
dict.set("key", 1)   // 添加 string 键后变为 Dict[string, int]
print(type(dict))    // "Dict[string, int]"
dict.set("key2", "hello")  // ❌ 错误：期望 int，传入 string

// 混合类型字典：类型为 Dict[string, any]
var mixed = {"a": 1, "b": "hello", "c": true}
print(type(mixed))   // "Dict[string, any]"
mixed.set("d", 42)   // ✅ 可以添加 int
mixed.set("e", "world")  // ✅ 可以添加 string
print(type(mixed))   // "Dict[string, any]"（保持 any 类型）

// int 键字典：类型为 Dict[int, string]
var int_keys = {1: "one", 2: "two"}
print(type(int_keys))  // "Dict[int, string]"
int_keys.set(3, "three")   // ✅ 可以添加 int 键
int_keys.set("4", "four")  // ❌ 错误：期望 int 键，传入 string

// 混合键字典：类型为 Dict[any, int]
var mixed_keys = {1: 100, "a": 200}
print(type(mixed_keys))  // "Dict[any, int]"
mixed_keys.set(3, 300)     // ✅ int 键
mixed_keys.set("b", 400)   // ✅ string 键
```

**重要区别**：

- `Dict`（空字典）：添加第一个值后**更新**为具体类型
- `Dict[string, any]`（混合字典）：保持 `any` 类型，**可以添加任何类型值**

**建议**：尽量初始化时就明确键和值类型：

```leno
var dict = {"a": 1, "b": 2}      // ✅ 明确为 Dict[string, int]
var id_map = {100: "张三", 200: "李四"}  // ✅ 明确为 Dict[int, string]

// 或者直接声明空字典类型
Dict[string, int] dict           // ✅ 空的 Dict[string, int]
Dict[int, string] id_map2 = {}   // ✅ 空的 Dict[int, string]
```

### 📋 字典类型检查覆盖

所有**修改**字典值的操作都会进行类型检查：

| 操作 | 示例 | 类型检查 |
| ---- | ---- | -------- |
| `set` | `dict.set("key", 1)` | ✅ 检查值类型 |
| 索引赋值 | `dict["key"] = 1` | ✅ 检查值类型 |
| 点号赋值 | `dict.key = 1` | ✅ 检查值类型 |

```leno
var dict = {}
dict.set("a", 1)     // ✅ 类型变为 Dict[string, int]
dict["b"] = 2        // ✅ 正确
dict.c = 3           // ✅ 正确（点号访问）
dict.set("d", "bad") // ❌ 报错：期望 int
dict["e"] = "bad"    // ❌ 报错：期望 int

// int 键字典的类型检查
var id_map = {}
id_map.set(1, "张三")    // ✅ 类型变为 Dict[int, string]
id_map[2] = "李四"       // ✅ 正确
id_map.set("3", "王五")  // ❌ 报错：期望 int 键，传入 string
id_map.set(4, 123)       // ❌ 报错：期望 string 值，传入 int
```

### 🔥 set 方法与索引赋值的区别

虽然 `d["key"] = value`（索引赋值）和 `d.set("key", value)`（方法调用）都能给字典添加键值对，但两者有以下重要区别：

| 特性 | `d.set(key, value)` | `d["key"] = value` |
|------|---------------------|---------------------|
| **性能** | 稍慢（约 50%） | ✅ **更快**（推荐） |
| **返回值** | 返回 `null` | 无返回值 |
| **链式调用** | 不支持 | 不支持 |
| **字节码** | `OP_DICT_SET` | `OP_INDEX_SET` |

**性能差异原因**：

- `d.set()`：编译器优化为专用字节码，但 VM 内部直接调用 `dict_set()`
- `d[]`：通用索引赋值，VM 先判断类型（数组/字典）再处理，但现代 CPU 分支预测使其更快

**实际测试**（10万次插入）：

```leno
import times

var d1 = {}
var start = times.ms()
for 0:100000 to i {
    d1.set("key_" + i, i)   // 约 140-170ms
}
print("set 方法: " + (times.ms() - start) + " ms")

var d2 = {}
start = times.ms()
for 0:100000 to i {
    d2["key_" + i] = i       // 约 90-110ms（更快！）
}
print("索引赋值: " + (times.ms() - start) + " ms")
```

> **💡 建议**：优先使用 `d["key"] = value` 语法，性能更好且更直观。`set` 方法主要用于方法引用场景（如 `arr.map(dict.set)`）。

**访问方式**：

```leno
var user = {
    name: "张三",
    address: {
        city: "北京",
        street: "朝阳路"
    }
}

// 两种方式访问
print(user["name"])           // 方括号访问
print(user.name)              // 点号访问（推荐）
print(user["address"]["city"]) // 嵌套访问
print(user.address.city)      // 点号嵌套访问
```

### 🔗 嵌套类型

数组和字典可以互相嵌套，类型精确推断：

```leno
// 数组包含字典
var arrDict = [{"name": "a"}, {"name": "b"}]
print(type(arrDict))  // Array[Dict[string, string]]

// 字典包含数组
var dictArr = {"items": [1, 2, 3]}
print(type(dictArr))  // Dict[string, Array[int]]

// int 键字典包含数组
var id_items = {1: [10, 20], 2: [30, 40]}
print(type(id_items))  // Dict[int, Array[int]]

// 深层嵌套字典
var deep = {"level1": {"level2": {"level3": "value"}}}
print(type(deep))     // Dict[string, Dict[string, Dict[string, string]]]

// 显式声明嵌套类型
Dict[string, Dict[string, int]] nested = {
    level1: {a: 1, b: 2}
}
nested.set("level2", {c: 3})     // ✅ 正常
nested.set("level3", {d: "bad"}) // ❌ 错误：期望 Dict[string, int]
```

**只读操作**（如 `len()`, `has()`, `keys()`, `copy()`）不影响类型检查。

## 1.5 struct 嵌套

struct 支持嵌套，即 struct 字段可以是另一个 struct 类型：

### ✅ 基本嵌套示例

```leno
struct Point
{
    int x = 0
    int y = 0
}

struct Size
{
    int width = 100
    int height = 100
}

struct Rect
{
    Point position      // 嵌套 Point 类型
    Size size           // 嵌套 Size 类型
}

main()
{
    var r = new Rect()
    // 嵌套对象自动初始化
    print(r)  // Rect{position=Point{x=0, y=0}, size=Size{width=100, height=100}}
    
    // 访问嵌套字段
    r.position.x = 10
    r.position.y = 20
    r.size.width = 200
    r.size.height = 150
    
    print(r.position.x)  // 10
    print(r.size.width)  // 200
}
```

### ⚠️ 重要：自引用 struct 必须设置 null 默认值

当 struct 引用自身类型（如链表节点）时，**必须设置默认值为 null**，否则会无限递归创建：

```leno
// ❌ 错误：会导致栈溢出（无限递归）
struct Node
{
    int value
    Node next    // 没有默认值，会无限创建 Node
}

// ✅ 正确：设置 null 默认值
struct Node
{
    int value
    Node next = null    // 默认为 null，避免递归
}

struct LinkedList
{
    Node head = null    // 链表头默认为 null
    int count = 0
}
```

### 🔍 struct 与类型守卫

类型守卫可以将 `var` 类型收窄为具体的 struct 类型，从而访问字段：

```leno
struct Student {
    string name = ""
    int age = 0
}

// 接受任何类型的参数
func process(var obj) {
    // 使用类型守卫检查并收窄类型
    if obj is Student {
        // 在守卫块内，obj 被视为 Student 类型
        print(obj.name)   // ✅ 可以访问字段
        print(obj.age)
    } else {
        print("不是 Student 类型")
    }
}

main() {
    var s = new Student()
    s.name = "张三"
    s.age = 18
    process(s)   // 输出: 张三  18
    
    process(123) // 输出: 不是 Student 类型
}
```

**类型守卫在闭包中也有效：**

```leno
func test(var data) {
    if data is Student {
        // 守卫变量在闭包中保持收窄类型
        func getInfo():string {
            return data.name + " " + _str(data.age)
        }
        print(getInfo())
    }
}
```

### 📝 struct 字段使用空数组/字典默认值

struct 字段可以使用 `[]` 和 `{}` 作为默认值，避免 null 检查：

```leno
struct Class {
    string name = ""
    Array[Student] students = []     // ✅ 空数组，可直接使用
    Dict[string, int] scores = {}    // ✅ 空字典，可直接使用
    
    func addStudent(Student s) {
        students.add(s)     // ✅ 不需要检查 null
    }
}

main() {
    var c = new Class()
    print(c.students.len())   // 输出: 0，不是 null
    c.students.add(new Student()) // ✅ 正常工作
}
```

**重要区别：**

| 写法 | 结果 | 说明 |
|------|------|------|
| `Array[int] arr = []` | ✅ 空数组 | 可直接使用 `add()` 等方法 |
| `Array[int] arr = null` | ⚠️ null | 使用前必须检查 `is null` |

### 📐 struct vs 数组+字典

虽然 struct 功能可以用数组+字典实现，但有本质区别：

```leno
// === struct 版本 ===
struct Student {
    string name = ""
    int age = 0
}

var s = new Student()
s.age = 18
int a = s.age   // ✅ s.age 是 int，无需转换

// === 字典版本 ===
var s = {name: "", age: 0}
s.age = 18
int a = s.age   // ❌ 错误：any 不能赋值给 int
int a = _int(s.age)  // ✅ 需要显式转换
```

**性能对比**（10000 个学生，计算 1000 次）：

| 版本 | 创建时间 | 计算时间 |
|------|----------|----------|
| struct | 16 ms | **2390 ms** |
| 字典 | 15 ms | **6031 ms** |

**struct 快 2.5 倍**，因为：
- 直接字段访问（编译期确定偏移量）
- 无需类型转换
- 方法内联优化

### 💡 输出格式化技巧

使用插值字符串 `$"..."` 比字符串拼接更简洁：

```leno
struct Point {
    int x = 0
    int y = 0
}

main() {
    var p = new Point()
    p.x = 10
    p.y = 20
    
    // ❌ 拼接需要显式转换
    print("(" + _str(p.x) + ", " + _str(p.y) + ")")
    
    // ✅ 插值自动转换
    print($"({p.x}, {p.y})")   // 输出: (10, 20)
    
    // 也可以使用 format
    import strings
    print(strings.format("({0}, {1})", p.x, p.y))
}
```

### ✅ struct 字段的数组和字典默认值

struct 字段支持使用空数组 `[]` 和空字典 `{}` 作为默认值：

```leno
struct Student {
    string name = ""
    int age = 0
    Array[int] scores = []    // ✅ 空数组作为默认值
}

struct Class {
    string name = ""
    Array[Student] students = []    // ✅ 空数组作为默认值
    Dict[string, string] metadata = {}   // ✅ 空字典作为默认值
    
    func addStudent(Student s) {
        students.add(s)     // ✅ 可以直接使用，不需要检查 null
    }
    
    func getAverageAge():float {
        if (students.len() == 0) {
            return 0.0
        }
        int total = 0
        for students to s {
            total = total + s.age
        }
        float result = total
        return result / students.len()
    }
}

main() {
    var mathClass = new Class()
    // students 已经被初始化为空数组，不是 null
    print(mathClass.students.len())   // 输出: 0
    
    var s1 = new Student()
    s1.name = "张三"
    s1.age = 18
    s1.scores = [85, 90, 78]
    
    mathClass.addStudent(s1)   // ✅ 正常工作
    print(mathClass.students.len())   // 输出: 1
}
```

**重要区别**：

| 写法 | 结果 | 说明 |
|------|------|------|
| `Array[int] arr = []` | ✅ 空数组 | 可以直接使用 `add()` 等方法 |
| `Array[int] arr = null` | ⚠️ null | 使用前必须检查 `is null` |
| `Dict[string, int] d = {}` | ✅ 空字典 | 可以直接使用 `set()` 等方法 |
| `Dict[string, int] d = null` | ⚠️ null | 使用前必须检查 `is null` |

**建议**：如果字段是需要经常操作的集合类型，使用 `[]` 或 `{}` 作为默认值，避免 null 检查。

### 🔗 链表实现示例

利用 struct 嵌套可以实现完整的数据结构：

```leno
struct Node
{
    int value
    Node next = null
}

struct LinkedList
{
    Node head = null
    int count = 0
}

// 在链表尾部添加节点
// 注意：参数必须使用具体类型 LinkedList，不能用 var！
func list_add(LinkedList list, int value)
{
    var new_node = new Node()
    new_node.value = value
    
    if (list.head == null)
    {
        list.head = new_node
    }
    else
    {
        var current = list.head
        while (current.next != null)
        {
            current = current.next
        }
        current.next = new_node
    }
    list.count = list.count + 1
}

// 打印链表
func list_print(LinkedList list)
{
    print("链表: ")
    var current = list.head
    while (current != null)
    {
        print(current.value)
        print(" -> ")
        current = current.next
    }
    print("null")
}

main()
{
    var list = new LinkedList()
    
    list_add(list, 10)
    list_add(list, 20)
    list_add(list, 30)
    
    list_print(list)        // 输出: 10 -> 20 -> 30 -> null
    print("数量: ")
    print(list.count)       // 输出: 3
    
    // 访问特定节点
    print("第二个节点: ")
    print(list.head.next.value)  // 输出: 20
}
```

### ⚠️ 为什么链表参数不能用 var？

这是**编译器类型检查**的限制：

| 参数类型 | 能否访问字段 | 说明 |
|---------|------------|------|
| `LinkedList list` | ✅ 可以 | 编译器知道类型，生成字段访问指令 |
| `var list` | ❌ 不行 | 编译器不知道类型，无法识别 `.head` 是字段 |

```leno
// ✅ 正确：具体类型参数
func list_add(LinkedList list, int value)
{
    list.head = new_node    // 编译器知道 list 是 LinkedList，可以访问 .head
}

// ❌ 错误：var 参数
func list_add(var list, int value)
{
    list.head = new_node    // 编译报错：对象没有此方法
    // 因为编译器不知道 list 是什么类型，无法识别 .head 是字段
}
```

**底层原因**：
- `list.head` 需要编译器知道 `head` 是第几个字段（生成 `OP_GET_FIELD`）
- `var` 参数类型为 `any`，编译器没有 struct 定义信息
- 只能尝试运行时查找 `head` 方法（`OP_GET_PROPERTY`），找不到就报错

### var vs 具体类型参数对比

| 特性 | 具体类型（如 `LinkedList`） | var |
|------|---------------------------|-----|
| 类型检查 | 编译期 | 运行期 |
| 字段访问 | ✅ 支持 | ❌ 不支持 |
| 方法调用 | ✅ 支持 | ✅ 支持（运行时查找）|
| 索引访问（`arr[0]`） | ✅ 支持 | ✅ 支持（通用操作）|
| 比较运算 | ✅ 支持 | ✅ 支持 |
| 打印 | ✅ 支持 | ✅ 支持 |

**规则总结**：
- 需要**访问 struct 字段** → 用**具体类型**参数
- 只需要**打印、比较、索引访问** → 可以用 **var** 参数

## 2. 函数参数

### ✅ 推荐：写具体类型

```leno
func add(int a, int b):int {
    return a + b
}

func process(string s, Array[int] arr):string {
    // ...
}
```

### ⚠️  用 `var` 会丢失编译时类型信息（重要！）

```leno
func test(var c) {
    int a = c    // ❌ 编译报错：any 不能赋给 int
}

// 需要显式转换才能赋值给具体类型变量
func test(var c) {
    int a = _int(c)   // ✅ 编译通过
}
```

**为什么 var 参数不能推断类型？**

```leno
func process(var x) {    // x 永远是 any，不会根据调用推断
    // 即使 process(123) 调用，x 在函数内部仍然是 any
}

process(123)        // x 是 any，不是 int！
process("hello")    // x 是 any，不是 string！
```

> **关键设计**：`var` 参数**不推断、不特例化**。函数只编译一次，参数类型就是 `any`。

**如果需要在函数内部使用具体类型：**

````leno
// 方案1：类型守卫（推荐）
func process(var x) {
    if x is int {
        int n = x      // ✅ 守卫后收窄为 int
        return n * 2
    }
    return 0
}

> **⚠️ 重要：类型守卫的作用域**
>
> 类型守卫只在 `if` 块**内部**有效，离开作用域后自动恢复为原类型：
>
> ```leno
> func test(var cc) {
>     if cc is int {
>         int b = cc     // ✅ 守卫内 cc 是 int
>     }
>     // 离开 if 后，cc 恢复为 any
>     int tt = cc        // ❌ 错误：any 不能赋给 int
>     int tt = _int(cc)  // ✅ 需要显式转换
> }
> ```

// 方案2：直接声明参数类型（最清晰）
func process(int x) {   // ✅ x 就是 int
    return x * 2
}

// 方案3：显式转换（你知道类型时）
func process(var x) {
    int n = _int(x)    // ✅ 强制转换
    return n * 2
}
````

**但有个好消息**：`any` 在**运行时**可以直接参与运算！

```leno
func fib(var n) {        // n 是 any，但运行时实际是 int
    if n <= 1 {          // ✅ 可以比较，运行时检查实际类型
        return n
    }
    return fib(n-2) + fib(n-1)  // ✅ 可以算术运算
}

fib(10)  // 正常工作，返回 55
```

**关键区别**：

- **编译时**：`any` 不能隐式转换给 `int` 变量（严格检查）
- **运行时**：`any` 如果实际存储的是数值，可以直接运算（灵活执行）

| 场景                | 代码示例              | 结果   | 说明                     |
| ----------------- | ----------------- | ---- | ---------------------- |
| `any` 直接运算        | `n - 2`           | ✅ 允许 | 运行时检查，数值可运算            |
| `any` 赋值给 `int`   | `int a = n`       | ❌ 禁止 | 编译时检查，any 不能隐式转 int    |
| `any` 运算后赋给 `int` | `int a = n - 2`   | ❌ 禁止 | 运算结果还是 any，需要 `_int()` |
| `any` 显式转换后赋值     | `int a = _int(n)` | ✅ 允许 | 显式转换，编译通过              |

> **口诀**：运算看运行时，赋值看编译时！

**`_int()`** **的行为**：

- `int` → `int`（直接返回）
- `float` → `int`（截断小数）
- `string "123"` → `int 123`（解析成功）
- `string "abc"` / `string "12b3"` → 抛出运行时错误（解析失败）

### ✅ 什么时候用 `var` 参数？

```leno
// 真的需要接受任何类型时
func print_any(var x) {
    print(type(x))
}

// 泛型/多态场景
func map(var arr, func f)  // 接受任何数组
```

## 2.5 默认参数

LenoC 支持为函数参数指定默认值，调用时如果省略该参数，则自动使用默认值。

### ✅ 基本语法

```leno
func add(int x, int y = 10):int {      // y 的默认值为 10
    return x + y
}

print(add(1))       // 输出: 11 (1 + 10)
print(add(1, 20))   // 输出: 21 (1 + 20)
```

### ✅ 多个默认参数

```leno
func greet(string name, string prefix = "Hello", string suffix = "!"):string {
    return prefix + " " + name + suffix
}

print(greet("Alice"))              // Hello Alice!
print(greet("Alice", "Hi"))        // Hi Alice!
print(greet("Alice", "Hi", "...")) // Hi Alice...
```

### ⚠️ 重要规则

#### 规则 1：有默认值的参数必须在最后

```leno
// ❌ 错误：无默认值的参数不能在有默认值的参数之后
func bad(int x = 10, int y) { }     // 编译错误

// ✅ 正确：所有有默认值的参数必须在末尾
func good(int x, int y = 10) { }    // OK
func good2(int x, int y = 10, int z = 20) { }  // OK
```

#### 规则 2：默认值必须是字面量常量

```leno
// ✅ 允许的字面量
func test1(int x = 10) { }              // 数字
func test2(float x = 3.14) { }          // 浮点数
func test3(string s = "hello") { }      // 字符串
func test4(bool b = true) { }           // 布尔值
func test5(var x = null) { }            // null

// ❌ 错误：默认值不能是表达式或函数调用
func bad1(int x = someFunc()) { }       // 编译错误
func bad2(int x = 1 + 2) { }            // 编译错误
func bad3(int x = y) { }                // 编译错误（y 是变量）
```

#### 规则 3：默认值类型必须与参数类型兼容

```leno
// ✅ int 可以自动升级为 float
func test1(float x = 10) { }            // OK: int → float

// ❌ float 不能降级为 int
func test2(int x = 3.14) { }            // 编译错误

// ❌ 类型完全不匹配
func test3(int x = "hello") { }         // 编译错误
func test4(string s = 123) { }          // 编译错误
```

#### 规则 4：var 参数的默认值会推断具体类型

```leno
func test(var a, var b = 0) {      // b 推断为 int，不是 any
    print(type(a))                  // "any"
    print(type(b))                  // "int"
}

test(42)           // a=42(any), b=0(int)
test("hi", 10)     // a="hi"(any), b=10(int)
```

**推断规则**：
- `var x = 0` → `int`
- `var x = 3.14` → `float`
- `var x = "hello"` → `string`
- `var x = true` → `bool`
- `var x = null` → `null`

### 📋 参数数量检查

调用函数时，参数数量必须满足：**必选参数数量 ≤ 实际参数数量 ≤ 总参数数量**

```leno
func test(int x, int y = 10, int z = 20) { }

// 必选参数: 1 (x)
// 总参数: 3 (x, y, z)

test()              // ❌ 错误：至少需要 1 个参数
test(1)             // ✅ OK: x=1, y=10, z=20
test(1, 2)          // ✅ OK: x=1, y=2, z=20
test(1, 2, 3)       // ✅ OK: x=1, y=2, z=3
test(1, 2, 3, 4)    // ❌ 错误：最多接受 3 个参数
```

### 💡 最佳实践

1. **为常用值提供默认值**

```leno
// ✅ 好的设计：count 默认为 1，offset 默认为 0
func fetchData(string url, int count = 1, int offset = 0):Array { }

fetchData("/api/users")         // 获取 1 条，从 0 开始
fetchData("/api/users", 10)     // 获取 10 条，从 0 开始
fetchData("/api/users", 10, 20) // 获取 10 条，从 20 开始
```

2. **使用具体类型而不是 var + 默认值来推断**

```leno
// ❌ 不推荐：虽然能工作，但意图不清晰
func bad(var x = 0) { }          // x 推断为 int，但看起来像 any

// ✅ 推荐：明确声明类型
func good(int x = 0) { }         // 清晰明确，x 就是 int
```

3. **默认参数和类型守卫结合**

```leno
func process(var data, bool verbose = false) {
    if verbose {
        print("处理中: " + type(data))
    }
    // 处理 data...
}

process(42)              // 静默处理
process(42, true)        // 详细输出
```

## 3. 函数返回类型

### ✅ 推荐：显式声明返回类型

```leno
func sum(Array[int] arr):int {
    int total = 0
    for 0:arr.len() to i {
        total = total + arr[i]
    }
    return total
}

// 调用时无需转换
int result = sum(arr)
```

### ⚠️  不写返回类型的代价

```leno
func sum(Array[int] arr) {      // 返回 any
    var total = 0
    return total
}

// 调用时麻烦
var result = sum(arr)      // result 是 any
int x = result + 1         // ❌ 报错：any 不能运算
int y = _int(result) + 1   // ✅ 必须显式转换
```

**结论**：省略返回类型省了几个字符，但后续处处要转换，不划算！

## 4. 类型转换

| 转换函数        | 用途        | 失败时的行为  |
| ----------- | --------- | ------- |
| `_int(x)`   | 转为 int    | 抛出运行时错误 |
| `_float(x)` | 转为 float  | 抛出运行时错误 |
| `_bool(x)`  | 转为 bool   | 抛出运行时错误 |
| `_str(x)`   | 转为 string | 抛出运行时错误 |
| `_int32(x)` | 截断为 32 位有符号整数（环绕） | 抛出运行时错误 |
| `_uint32(x)` | 转为 32 位无符号整数（0~4294967295） | 抛出运行时错误 |
| `_int64(x)` | 截断为 64 位有符号整数（环绕） | 抛出运行时错误 |

```leno
func test(var x):int {
    return _int(x)   // 转换失败会报错！
}

test("12b3")   // ❌ 运行时错误：无法将字符串转换为整数
test("123")    // ✅ 返回 123
```

**注意**：转换函数在无法转换时会**抛出运行时错误**。如果需要安全转换，先判断类型：

```leno
if x is int {
    return x
} else {
    print("错误：需要 int")
    return 0
}
```

## 5. 运算规则

### 5.1 算术运算限制

以下类型**不能**参与算术运算（`+`、`-`、`*`、`/`、取模、位运算）：

| 类型 | 示例 | 结果 |
|------|------|------|
| bool | `true + 1` | ❌ 编译错误 |
| string | `"hello" - "lo"` | ❌ 编译错误 |
| string | `"ha" * 3` | ❌ 编译错误 |

```leno
// ❌ 错误：bool 不能参与算术运算
var a = true + 1           // 编译错误：bool 类型不能参与算术运算
var b = false * 2          // 编译错误

// ❌ 错误：string 不能参与算术运算
var c = "hello" - "lo"     // 编译错误：string 类型不能参与算术运算
var d = "ha" * 3           // 编译错误
var e = "hello" / 2        // 编译错误

// ✅ 正确：数值类型可以运算
var f = 1 + 2              // int
var g = 3.0 * 2            // float
```

### 5.1.1 除法运算规则

LenoC 的除法运算符 `/` 根据操作数类型决定结果类型。`int` 自动支持任意精度整数（内部自动使用 BigInt），外部统一视为 `int`：

| 操作数类型 | 结果类型 | 说明 | 示例 |
|-----------|---------|------|------|
| `int / int` | `int` | 整数除法（截断小数） | `5 / 2 = 2` |
| `int / float` | `float` | 浮点除法 | `5 / 2.0 = 2.5` |
| `float / int` | `float` | 浮点除法 | `5.0 / 2 = 2.5` |

```leno
// 整数除法
var a = 5 / 2              // 结果是 2 (int)，不是 2.5
var b = 10 / 3             // 结果是 3 (int)，不是 3.333...

// 浮点除法
var c = 5.0 / 2            // 结果是 2.5 (float)
var d = 5 / 2.0            // 结果是 2.5 (float)

// 超大整数除法（自动 BigInt 精度）
var big = 10000000000000000000
var e = big / 10           // 结果是 1000000000000000000 (int)，不是 1e+18
var f = big / 2.0          // 结果是 5e+18 (float)

// 混合运算
var g = 7 / 2              // int: 3
var h = 7.0 / 2            // float: 3.5
var i = 7 / 2.0            // float: 3.5
```

**设计原则**：
- 整数相除得整数，避免意外的浮点结果
- 需要小数时显式使用 float：`5.0 / 2` 或 `float(5) / 2`
- 超大整数有 float 参与时转为 float，否则保持整数精度
- 超大整数除以 float 时，内部转为 double 计算（超大数可能丢失精度）

### 5.2 比较运算规则

#### 相等比较 `==` 和 `!=`

| 场景 | 示例 | 结果 | 说明 |
|------|------|------|------|
| 同类型数值 | `1 == 1.0` | `true` | 数值类型（int/float）之间**值比较**，超大整数自动支持 |
| 同类型 bool | `true == true` | `true` | 同类型比较 |
| 不同类型 | `true == 1` | `false` | bool ≠ int，严格类型比较 |
| 不同类型 | `"1" == 1` | `false` | string ≠ int，严格类型比较 |

```leno
// 数值类型之间值比较
print(1 == 1.0)            // true（数学上相等）
print(1 == 1)              // true
print(1.0 == 1.0)          // true

// 不同类型返回 false
print(true == 1)           // false（bool ≠ int）
print("1" == 1)            // false（string ≠ int）
print(true == 1.0)         // false（bool ≠ float）

// 数组比较（元素数值类型值比较）
var arr1 = [1, 2.0, 3]
var arr2 = [1.0, 2, 3.0]
print(arr1 == arr2)        // true（元素数值相等）
```

#### 大小比较 `<`、`>`、`<=`、`>=`

**禁止跨类型比较**，以下情况会编译错误：

| 场景 | 示例 | 结果 |
|------|------|------|
| 数值 vs string | `1 < "2"` | ❌ 编译错误 |
| bool vs bool | `true < false` | ❌ 编译错误 |
| bool vs 数值 | `true < 1` | ❌ 编译错误 |

```leno
// ❌ 错误：跨类型比较
print(1 < "2")             // 编译错误：数值类型不能和 string 类型进行大小比较
print(true < false)        // 编译错误：不兼容的类型不能进行大小比较

// ✅ 正确：同类型数值比较
print(1 < 2)               // true
print(3.0 > 2)             // true（int 和 float 可以比较）
print("a" < "b")           // true（string 之间可以比较）
```

## 6. 类型守卫详解

类型守卫（Type Guard）通过 `is` 关键字在运行时检查类型，并在编译时收窄变量类型。

### 5.1 基本语法

```leno
if x is int {
    // x 在这个块内被视为 int 类型
    int n = x + 10    // ✅ 可以直接使用
}
```

#### 否定类型守卫（`not is`）

使用 `not is` 检查变量**不是**某种类型：

```leno
if x not is int {
    print("x 不是 int")
} else {
    // else 分支内 x 是 int
    int n = x + 10   // ✅ 可以收窄
}
```

#### `is null` 检查

使用 `is null` 检查变量是否为 `null`：

```leno
var a = null
var b = "hello"
if a is null or b is null {
    print("至少一个是 null")
}
```

支持的类型守卫：

| 类型守卫        | 检查目标 | 示例               |
| ----------- | ---- | ---------------- |
| `is int`    | 整数   | `if x is int`    |
| `is float`  | 浮点数  | `if x is float`  |
| `is string` | 字符串  | `if x is string` |
| `is bool`   | 布尔值  | `if x is bool`   |
| `is Array`  | 数组   | `if x is Array`  |
| `is Array[T]` | 特定元素类型数组 | `if x is Array[Point]` |
| `is Dict`   | 字典   | `if x is Dict`   |
| `is null`   | 空值   | `if x is null`   |
| `obj.field is Type` | Dict 字段 | `if s.age is int` |

> **⚠️ 注意：`is Array`** **的特殊行为**
>
> `is Array` 匹配**所有数组类型**（包括 `Array[int]`、`Array[string]` 等），但**不会收窄类型**：
>
> ```leno
> var arr = [1, 2, 3]      // arr 是 Array[int]
> if arr is Array {         // ✅ 匹配成功
>     arr.add("hello")      // ❌ 错误：期望 int，传入 string
> }
> ```
>
> 原因：`is Array` 只确认是数组，不确认元素类型，所以保持原类型 `Array[int]`。
>
> **多分支数组类型守卫**：
>
> ```leno
> func process(var arr) {
>     if arr is Array[int] {           // 检查是否为 int 数组
>         print("int 数组")
>         arr.add(1)                   // ✅ 可以添加 int
>     } else if arr is Array[string] { // 检查是否为 string 数组
>         print("string 数组")
>         arr.add("hello")             // ✅ 可以添加 string
>     } else {
>         print("其他类型")
>     }
> }
>
> process([1, 2, 3])       // 输出: int 数组
> process(["a", "b"])      // 输出: string 数组
> ```
>
> **重要**：如果数组类型与守卫类型不匹配（如 `Array[int]` 用 `is Array[string]` 守卫），**不会收窄**，保持原类型。这是为了防止类型不安全的操作。

#### `Array[Struct]` 类型守卫与字段访问

当使用 `Array[Struct]` 类型守卫时，数组元素会被收窄为具体的 struct 类型，可以直接访问字段：

```leno
struct Point {
    int x
    int y
}

func process_points(var points) {
    if points is Array[Point] {
        var p = points[0]      // p 被识别为 Point 类型
        int x_val = p.x        // ✅ 可以直接访问字段，类型为 int
        int y_val = p.y        // ✅ 可以直接访问字段，类型为 int
        print("Point: (" + x_val + ", " + y_val + ")")
    }
}

// 创建 Point 数组
var arr = []
arr.add(new Point(x = 10, y = 20))
arr.add(new Point(x = 30, y = 40))
process_points(arr)   // 输出: Point: (10, 20)
```

**关键特性**：
- struct 添加到数组后**保留完整的类型信息**
- `Array[Point]` 类型守卫可以正确识别元素类型
- 类型守卫内部，`p.x` 和 `p.y` 被推断为 `int` 类型，无需 `_int()` 转换

对比 `Array`（无泛型）类型守卫：

```leno
func process_any_array(var points) {
    if points is Array {
        var p = points[0]      // p 是 any 类型
        var x_val = p.x        // x_val 是 any 类型
        int x = _int(x_val)    // 需要显式转换
    }
}
```

**建议**：处理 struct 数组时，使用 `Array[StructType]` 类型守卫可以获得更好的类型安全和代码简洁性。

#### Dict 字段访问类型守卫

类型守卫支持对 Dict 字段访问进行收窄，语法为 `obj.field is Type`：

```leno
var s = {name: "张三", age: 25, scores: [85, 90, 78]}

// 单个字段守卫
if s.age is int {
    int age = s.age        // ✅ s.age 被收窄为 int
    print(age)
}

// 多个字段守卫（and 连接）
if s.name is string and s.age is int {
    string name = s.name   // ✅ s.name 被收窄为 string
    int age = s.age        // ✅ s.age 被收窄为 int
    print(name + " 年龄: " + age)
}

// 字段为 Array 时的守卫
if s.scores is Array {
    int total = 0
    for s.scores to score {
        if score is int {
            total = total + score
        }
    }
    float avg = _int(total) / _int(s.scores.len())
    print("平均分: " + _str(avg))
}
```

**循环内的字段守卫**：

```leno
var students = []
for 0:100 to i {
    var s = {name: "学生" + i, age: 18 + (i % 5)}
    students.add(s)
}

int totalAge = 0
for students to s {
    if s.age is int {
        totalAge = totalAge + s.age   // ✅ s.age 被收窄为 int
    }
}
```

**嵌套字段守卫**：

对于嵌套字段（如 `data.inner.count`），需要通过中间变量逐层守卫：

```leno
var data = {inner: {count: 5}}

// ❌ 不支持直接嵌套字段守卫
if data.inner.count is int {
    int n = data.inner.count   // ❌ 仍然是 any
}

// ✅ 使用中间变量逐层守卫
if data.inner is Dict {
    var inner = data.inner
    if inner.count is int {
        int count = inner.count   // ✅ 被收窄为 int
    }
}
```

**字段守卫收窄规则**：

| 写法 | 是否收窄 | 说明 |
|------|---------|------|
| `if x is int` | ✅ 收窄 `x` | 简单变量守卫 |
| `if s.age is int` | ✅ 收窄 `s.age` | Dict 字段守卫 |
| `if s.name is string and s.age is int` | ✅ 同时收窄 | 多字段守卫 |
| `if data.inner.count is int` | ❌ 不收窄 | 嵌套字段暂不支持 |
| `if s.age is int or s.name is string` | ❌ 不收窄 | or 条件不收窄 |

### 5.2 多条件类型守卫

#### `and` 条件（类型收窄）

使用 `and` 连接多个类型守卫条件时，**每个变量都会收窄**：

```leno
func test(var x, var y) {
    if x is int and y is string {
        int n = x        // ✅ x 收窄为 int
        string s = y     // ✅ y 收窄为 string
        print(n, s.len())
    }
}
```

#### `or` 条件（不收窄）

使用 `or` 连接多个类型守卫条件时，**不进行类型收窄**：

```leno
func test(var x, var y) {
    if x is int or y is string {
        // ⚠️ or 条件下不收窄，x 和 y 仍是 any
        string s = y     // ❌ 错误：无法将 any 赋值给 string
        int n = x        // ❌ 错误：无法将 any 赋值给 int
    }
}
```

**原因**：`or` 条件下只有一个条件满足，不能保证变量一定是该类型。例如 `test(42, 123)` 中 `x is int` 为真，但 `y` 是 `int` 不是 `string`。

**解决方案**：在 `or` 块内使用显式转换：

```leno
func test(var x, var y) {
    if x is int or y is string {
        if x is int {
            int n = x    // ✅ 单独判断后收窄
        }
        if y is string {
            string s = y // ✅ 单独判断后收窄
        }
    }
}
```

### 5.3 类型守卫的作用域规则

**✅ 有效场景：**

1. **直接使用** **`is`** **表达式**

```leno
func test(var x) {
    if x is int {
        int n = x     // ✅ 可以收窄
    }
}
```

1. **闭包中捕获类型守卫变量**

```leno
func test_closure(var a):int {
    if a is int {
        func inner():int {
            return a + 10  // ✅ a 被识别为 int
        }
        return inner()
    }
    return 0
}
```

**❌ 无效场景：**

1. **`is`** **表达式赋值给变量后不能收窄**

```leno
func test(var b) {
    var is_int = b is int   // is_int 是 bool 变量
    if is_int {
        int n = b           // ❌ 无法收窄，b 仍是 any
    }
}
```

1. **函数返回的 bool 不能用于收窄**

```leno
func check_type(var x):bool {
    return x is string
}

func test(var c) {
    if check_type(c) {
        string s = c        // ❌ 无法收窄，c 仍是 any
    }
}
```

1. **闭包内 var 参数保持 any（无守卫时不收窄）**

```leno
func test(var x) {
    func inner() {
        print(type(x))      // "any"
        int a = x           // ❌ 错误：无法将 any 赋值给 int
    }
    inner()
}
test(42)
```

**原因**：闭包捕获 `var` 参数时，如果没有类型守卫，`x` 保持 `any` 类型。这是安全的——没有守卫就不收窄，和非闭包场景行为一致。

### 5.4 作用域与恢复

类型守卫只在 `if` 块内部有效，离开后立即恢复为原类型：

```leno
func test(var cc) {
    if cc is int {
        int b = cc          // ✅ cc 是 int
    }
    // 离开 if 后，cc 恢复为 any
    int tt = cc             // ❌ 错误：any 不能赋给 int
    int tt = _int(cc)       // ✅ 需要显式转换
}
```

### 5.5 获取类型信息

使用 `type()` 函数获取变量类型：

```leno
var x = 10
print(type(x))      // "int"

var arr = [1, 2, 3]
print(type(arr))    // "Array[int]"

var empty = []
print(type(empty))  // "Array"
```

## 6.5 安全类型转换（as）

`as` 运算符在运行时检查类型，**匹配则返回原值，不匹配则返回 `null`**。与 `is`（返回 `bool`）不同，`as` 返回的是值本身或 `null`。

### 基本语法

```leno
var result = 表达式 as 类型名
```

### 基本类型转换

```leno
var x = 42
var xi = x as int        // 42（匹配，返回原值）
var xf = x as float      // 42.0（int→float 数值转换）
var xs = x as string     // null（不匹配，int 不是 string）

var f = 3.14
var fi = f as int        // 3（float→int 截断小数）
var ff = f as float      // 3.14（匹配，返回原值）

var s = "hello"
var ss = s as string     // "hello"（匹配）
var si = s as int        // null（不匹配，string 不是 int）
var sf = s as float      // null（不匹配）
```

### struct 类型转换

```leno
struct Dog {
    string name = ""
    func speak():string { return "Woof" }
}

struct Cat {
    string name = ""
    func speak():string { return "Meow" }
}

var dog = new Dog()
var d = dog as Dog       // Dog 实例（匹配，返回原值）
var c = dog as Cat       // null（不匹配，Dog 不是 Cat）
```

### face 类型转换（最常用场景）

`as` 最核心的用途是在 face 多态场景下做**安全向下转型**：

```leno
face Shape {
    func area():float
}

struct Circle impl Shape {
    float _radius = 1.0
    func area():float { return 3.14159 * _radius * _radius }
}

struct Rect impl Shape {
    float _width = 1.0
    float _height = 1.0
    func area():float { return _width * _height }
}

func describe(Shape s) {
    var c = s as Circle
    if c != null {
        return "Circle radius=" + _str(c._radius)    // ✅ 安全访问 Circle 字段
    }
    var r = s as Rect
    if r != null {
        return "Rect " + _str(r._width) + "x" + _str(r._height)
    }
    return "Unknown shape"
}

assert_eq(describe(new Circle()), "Circle radius=1")
assert_eq(describe(new Rect()), "Rect 1x1")
```

### `as` 与 `is` 的区别

| 特性 | `is` | `as` |
|------|------|------|
| 返回值 | `bool`（true/false） | 原值或 `null` |
| 用途 | 条件判断 | 安全转型 + null 检查 |
| 典型场景 | `if x is int { ... }` | `var c = s as Circle; if c != null { ... }` |

```leno
// is：只判断类型
if dog is Dog {
    print("是 Dog")          // 需要单独访问 dog
}

// as：判断类型 + 获取转型后的值
var d = dog as Dog
if d != null {
    print(d.name)            // ✅ d 已经是 Dog 类型，可直接访问字段
}
```

### `as` 与类型转换函数的区别

| 写法 | 语义 | 结果 |
|------|------|------|
| `42 as float` | 类型检查 + 数值转换 | `42.0`（int→float 自动转换） |
| `_float(42)` | 强制类型转换 | `42.0`（int→float 转换） |
| `3.14 as int` | 类型检查 + 数值转换 | `3`（float→int 截断小数） |
| `_int(3.14)` | 强制类型转换 | `3`（截断小数） |
| `42 as int` | 类型检查 | `42`（匹配，返回原值） |
| `"abc" as int` | 类型检查 | `null`（不匹配） |
| `_int("abc")` | 强制类型转换 | 运行时错误（解析失败） |

**核心区别**：
- `as` 是**安全类型检查**，不匹配返回 `null`；`int` ↔ `float` 之间会自动进行数值转换
- `_int()`/`_float()` 等是**强制类型转换**，转换失败抛出运行时错误

### null 值的 as 转换

```leno
var n = null as int        // null（null 不匹配任何类型）
```

## 6.6 switch 类型匹配（case is）

`switch` 支持 `case is` 按类型匹配分支，比层层 `if-is` 更简洁清晰。

### 基本语法

```leno
func process(var x) {
    switch x {
        case is int {
            print("整数: " + x)
        }
        case is string {
            print("字符串: " + x)
        }
        case is float {
            print("浮点数: " + x)
        }
        case is bool {
            print("布尔值: " + x)
        }
        default {
            print("其他类型")
        }
    }
}
```

### 类型收窄

`case is` 匹配成功后，分支内变量类型会被自动收窄：

```leno
switch x {
    case is int {
        int n = x + 10     // ✅ x 被收窄为 int
    }
    case is string {
        string s = x       // ✅ x 被收窄为 string
        print(s.len())
    }
}
```

### 值匹配和类型匹配混合

```leno
func process(var x) {
    switch x {
        case 0 {
            print("零")
        }
        case 1, 2, 3 {
            print("小数字: " + x)
        }
        case is int {
            print("其他整数: " + x)
        }
        case is string {
            print("字符串: " + x)
        }
        default {
            print("其他")
        }
    }
}
```

### struct 和 face 类型匹配

```leno
face Shape {
    func area():float
}

struct Circle impl Shape {
    float _radius = 1.0
    func area():float { return 3.14159 * _radius * _radius }
}

struct Rect impl Shape {
    float _width = 1.0
    float _height = 1.0
    func area():float { return _width * _height }
}

func describe(var s) {
    switch s {
        case is Circle {
            print("圆形，面积: " + s.area())    // ✅ s 被收窄为 Circle
        }
        case is Rect {
            print("矩形，面积: " + s.area())    // ✅ s 被收窄为 Rect
        }
        case is Shape {
            print("其他形状，面积: " + s.area()) // ✅ s 被收窄为 Shape
        }
        default {
            print("不是形状")
        }
    }
}
```

### 支持的类型守卫

| 类型守卫 | 检查目标 | 示例 |
|---------|---------|------|
| `case is int` | 整数 | `case is int { }` |
| `case is float` | 浮点数 | `case is float { }` |
| `case is string` | 字符串 | `case is string { }` |
| `case is bool` | 布尔值 | `case is bool { }` |
| `case is null` | 空值 | `case is null { }` |
| `case is StructName` | 结构体类型 | `case is Circle { }` |
| `case is FaceName` | face 接口类型 | `case is Shape { }` |
| 值匹配 | 具体值相等 | `case 0 { }`, `case "a", "b" { }` |

> **⚠️ 注意：`case`** **按书写顺序从上到下匹配**
>
> ```leno
> switch x {
>     case 0 { }            // 先匹配值 0
>     case 1, 2, 3 { }      // 再匹配多值
>     case is int { }       // 最后匹配 int 类型
>     case is string { }    // 匹配 string 类型
>     default { }           // 兜底
> }
> ```
>
> 把精确的值匹配放在泛化类型匹配前面，确保精确值优先命中。

**`switch case is`** **vs** **`if is` 对比：**

| 特性 | `switch case is` | `if is` |
|------|-----------------|--------|
| 结构 | 扁平，一目了然 | 层层嵌套 |
| 多类型分支 | ✅ 自然支持 | 需要 `else if` 链 |
| 类型收窄 | ✅ 每个 case 内收窄 | ✅ if 块内收窄 |
| default 分支 | ✅ 内置 | 需要最后的 `else` |
| 值+类型混合 | ✅ 同一 switch | 需要分开写 |

```leno
// ❌ if-is 链：层层缩进
func process(var x) {
    if x is int {
        // ...
    } else if x is string {
        // ...
    } else if x is float {
        // ...
    } else {
        // ...
    }
}

// ✅ switch case is：扁平清晰
func process(var x) {
    switch x {
        case is int { }
        case is string { }
        case is float { }
        default { }
    }
}
```

## 8. 常见错误

### ❌ 错误：var 参数直接赋给具体类型

```leno
func test(var c) {
    int a = c    // 报错：any 不能赋给 int
}
```

### ✅ 修复方案

```leno
// 方案1：显式转换（确保你知道 c 是什么）
func test(var c) {
    int a = _int(c)
}

// 方案2：参数写类型（推荐，安全）
func test(int c) {
    int a = c
}
```

### ❌ 错误：省略返回类型导致后续麻烦

```leno
func getValue() {      // 返回 any
    return 42
}

int x = getValue()     // ❌ 报错：any 不能赋给 int
int y = _int(getValue())  // ✅ 每次调用都要转换
```

### ✅ 修复：声明返回类型

```leno
func getValue():int {  // 返回 int
    return 42
}

int x = getValue()     // ✅ 直接可用
```

## 9. 核心原则

> **从确定到不确定，必须显式跨过边界**

> **编译时检查赋值，运行时检查运算**
>
> - 赋值：`int x = any_value` ❌ 需要 `_int()` 转换
> - 运算：`any_value + 1` ✅ 运行时自动处理

| 方向       | 示例          | 是否需要显式处理      |
| -------- | ----------- | ------------- |
| 确定 → 确定  | `int → int` | ❌ 不需要         |
| 确定 → 不确定 | `int → var` | ❌ 不需要         |
| 不确定 → 确定 | `var → int` | ✅ 需要 `_int()` |

> **⚠️ 重要：`Array` 与 `Array[any]` 的区别**
>
> `Array`（无类型参数）和 `Array[any]`（显式 any）**语义不同**：
>
> | 目标类型 | 接受 `Array[int]`? | 接受 `[]`? | 语义 |
> |----------|:---:|:---:|------|
> | `Array` | ✅ | ✅ | "我不关心元素类型，只要是数组就行" |
> | `Array[any]` | ❌ | ✅ | "我要求元素类型是 any" |
> | `Array[int]` | ✅ | ✅ | 相同元素类型 |
>
> ```leno
> var arr = [1, 2, 3]        // arr 是 Array[int]
> Array[int] bb = arr        // ✅ 相同类型
>
> Array any_arr = arr        // ✅ 允许：Array 是通配符，接受任何数组
> Array[int] arr2 = []       // ✅ 允许：空数组可以赋值给任何元素类型的 Array
> Array[any] any_arr2 = arr  // ❌ 错误：Array[int] 不能赋给 Array[any]
> ```
>
> **设计意图**：`Array`（裸类型）放弃元素类型信息，接收任意数组用于通用操作（遍历、长度等）；`Array[any]` 是明确要求元素为 any 类型，拒绝具体类型数组以防止类型约束丢失。

### ⚠️ 模块在数组中的类型行为

导入的模块放入数组后，类型会变为 `Dict`，这是**设计上的选择**：

```leno
import math, string_utils

var modules = [math, string_utils]  // 类型: Array[Dict[string, any]]

// ✅ 直接索引访问 - 正常工作
modules[0].add(1, 2)           // 可以调用
modules[1].trim("  hello  ")   // 可以调用

// ❌ 赋值给变量后丢失类型信息
var m = modules[0]             // 类型: Dict[unknown, unknown]
m.add(1, 2)                    // 错误：无法识别 add 方法

// ❌ for 循环中同样丢失类型
for modules to mod {
    mod.add(1, 2)              // 错误：无法识别 add 方法
}
```

**原因**：模块本质上是"名字→值"的字典映射。当模块放入数组时，编译器将其统一处理为 `Dict` 类型，以简化类型系统。直接索引访问时，编译器可以通过上下文推断具体类型；但赋值给变量或遍历时，类型信息丢失。

**解决方案**：

```leno
// 方案1：直接使用索引（推荐）
modules[0].add(1, 2)

// 方案2：使用函数数组代替模块数组
var adders = [math.add, string_utils.pad_start]
adders[0](1, 2)                // ✅ 正常工作

// 方案3：使用 struct 封装
struct MathOps {
    func add: func(int, int):int
}
var ops = [new MathOps(add = math.add)]
ops[0].add(1, 2)               // ✅ 正常工作
```

> **设计原则**：模块放入数组的场景较少见。如需动态选择模块功能，推荐使用**函数数组**或 **struct 数组**，它们提供更好的类型安全和代码清晰度。

## 10. 最佳实践示例

### ✅ 函数签名写清楚，内部用 var

```leno
// ✅ 最佳实践：函数签名写清楚
func add(int a, int b):int { return a + b }

// ✅ 内部变量用 var（简洁）
func process(Array[int] arr):int {
    var total = 0        // 推断为 int
    for arr to item {    // item 推断为 int
        total += item
    }
    return total
}

// ✅ 字典遍历：支持 key, value 双变量（键类型自动推断）
func process_dict(Dict[string, int] d) {
    for d to key, value {      // key 推断为 string，value 推断为 int
        print($"{key}: {value}")
    }
}
func process_int_dict(Dict[int, string] d) {
    for d to id, name {        // id 推断为 int，name 推断为 string
        print($"{id}: {name}")
    }
}
```

**原则**：

- **边界明确**：函数参数、返回类型 = 显式声明（对外接口清晰）
- **内部简洁**：局部变量 = `var` 推断（代码简洁）

### for 循环类型推断

| 遍历类型 | 变量1类型 | 变量2类型 | 示例 |
|---------|----------|----------|------|
| `Array[T]` | `T`（元素） | `int`（索引） | `for arr to item, idx` |
| `string` | `string`（字符） | `int`（索引） | `for str to char, idx` |
| `Dict[string, V]` | `string`（键） | `V`（值） | `for dict to key, value` |
| `Dict[int, V]` | `int`（键） | `V`（值） | `for dict to id, name` |
| `Dict[any, V]` | `any`（键） | `V`（值） | `for dict to key, value` |

## 11. 函数类型（func）

### 11.1 函数作为值

函数可以像普通值一样赋值给变量：

```leno
func foo():int { return 1 }
var a = foo        // a 是 func():int 类型
print(type(a))     // 输出: func
int b = a()        // 调用函数，b = 1
```

### 11.2 函数类型赋值规则

函数类型赋值遵循"**具体 → 通用**"原则：

| 方向 | 示例 | 结果 |
|------|------|------|
| 具体 → 通用 | `func(int):int → func` | ✅ 允许（安全，丢失签名信息） |
| 通用 → 具体 | `func → func(int):int` | ❌ 禁止（不安全） |
| 相同类型 | `func(int):int → func(int):int` | ✅ 允许 |
| 不同具体 | `func(int):int → func(string):int` | ❌ 禁止 |

```leno
func foo():int { return 1 }
func bar():string { return "hello" }
func baz():int { return 42 }

var a = foo        // a 是 func():int
a = baz            // ✅ 允许：相同类型 func():int
a = bar            // ❌ 错误：类型不匹配 func():string ≠ func():int

// 具体 → 通用（允许）
func takeFunc(func f) {    // f 是通用 func 类型
    var r = f(42)         // 编译放行，运行时检查
    print(r)
}
takeFunc(foo)             // ✅ 允许：func():int → func
```

**重要**：函数类型允许"具体 → 通用"的单向赋值，但禁止不同类型之间的互相赋值。

### 11.3 高阶函数

函数可以作为参数传递给其他函数：

```leno
// ✅ 推荐：明确指定函数参数返回类型
func apply(int x, func():int f):int {
    return f(x)
}
func double(int n):int { return n * 2 }
var result = apply(5, double)  // 输出: 10
```

**注意**：如果函数参数没有返回类型签名，则视为 `any`：

```leno
// func f 等同于 func():any
func apply2(int x, func f):int {
    return f(x)    // ❌ 错误：返回类型不匹配：期望 int，实际 any
}
```

**规则**：高阶函数的函数参数应该明确声明返回类型，否则返回类型视为 `any`，无法直接赋值给具体类型。

### 11.4 返回函数值与闭包

函数可以作为返回值，形成闭包（捕获外部变量）：

```leno
// 返回 func(int):int 类型
func makeAdder(int x):func(int):int {
    func adder(int n):int {
        return n + x  // 闭包捕获 x
    }
    return adder
}

var f = makeAdder(10)  // f 是 func(int):int
var result = f(5)       // result = 15，x 被捕获为 10
print(result)
```

**注意**：返回的函数类型必须严格匹配声明的返回类型：

```leno
// ❌ 错误：声明返回 func():int，实际返回 func(int):int
func badMakeAdder(int x):func():int {
    func adder(int n):int { return n + x }
    return adder  // 参数数量不匹配
}
```

### 11.5 func 通用类型的调用行为

当函数类型为 `func`（无签名）时，编译器不做参数检查，运行时正常执行：

```leno
func process(func f) {  // f 是通用 func 类型
    var result = f(42)  // 编译放行，运行时根据实际函数执行
    print(result)
}

func double(int n):int { return n * 2 }
process(double)  // ✅ 输出: 84
```

**运行时参数检查**：

```leno
func callWithFive(func f) {
    var result = f(5)  // 只传1个参数
    print(result)
}

func add(int x, int y):int { return x + y }
callWithFive(add)  // ❌ 运行时错误：期望 2 个参数，实际 1 个
```

### 11.6 函数类型兼容性

| 场景 | 示例 | 结果 |
|------|------|------|
| 函数赋值给变量 | `var a = foo` | ✅ 允许 |
| int 赋值给函数变量 | `a = 10` | ❌ 错误 |
| 函数重新赋值（相同类型） | `a = baz` | ✅ 允许 |
| 具体 → 通用 | `func(int):int → func` | ✅ 允许（安全，丢失签名信息） |
| 通用 → 具体 | `func → func(int):int` | ❌ 编译错误（不安全） |
| 不同具体类型 | `func(int):int → func(string):int` | ❌ 编译错误（类型不匹配） |
| 运行时参数数量不匹配 | `f(5)`（期望2个参数） | ❌ 运行时错误 |

## 12. 泛型函数

Leno 支持函数级泛型：在函数名后声明 `[T, U, ...]` 类型参数，编译器在调用时自动推断。

### ✅ 基本语法

```leno
// 定义泛型函数
func identity[T](T val):T {
    return val
}

func map[T, U](Array[T] arr, func(T):U fn):Array[U] {
    var result = []
    for arr to item {
        result.add(fn(item))
    }
    return result
}

func filter[T](Array[T] arr, func(T):bool pred):Array[T] {
    var result = []
    for arr to item {
        if pred(item) { result.add(item) }
    }
    return result
}
```

### ⚠️ 注意事项

1. **类型参数自动推断**，无需手动指定
2. **泛型参数可用在参数和返回类型**：`Array[T]`、`Dict[K,V]`、`func(T):U`、`Ptr[T]` 均可
3. **仅函数级泛型**：struct/face/enum 不支持类型参数
4. **返回值类型精确**：如 `map[int,int]` 调用返回 `Array[int]`，类型被正确推断
5. **`func(T):U`**：含泛型参数的函数类型参数需要显式定义具体版本再传入（如 `func double(int x):int`）
6. **泛型函数间可互相调用**：类型参数自动传播

### ❌ 不支持

```leno
// ❌ struct 不支持泛型
struct Box[T] { T value }    // 编译错误

// ❌ 不能显式指定类型参数
map[int, int](arr, double)   // 编译错误（类型参数由实参推断）
```

## 13. 类型别名（alias）

使用 `alias` 关键字为复杂类型定义简短别名，减少重复书写：

```leno
alias IntList = Array[int]
alias StrDict = Dict[string, string]
alias Callback = func(int, string):bool
alias IntMatrix = Array[IntList]         // 嵌套别名
```

### ✅ 使用方式

别名在定义后全局可用，与原生类型完全等价：

```leno
alias IntList = Array[int]

// 参数使用
func sum(IntList arr):int {
    var total = 0
    for arr to item { total = total + item }
    return total
}

// 返回类型使用
func make_list():IntList {
    return [1, 2, 3]
}

main() {
    // 变量声明
    IntList nums = [1, 2, 3, 4, 5]
    print(sum(nums))          // 15
    print(make_list())        // [1, 2, 3]
    print(type(nums))         // Array[int]（别名在编译期展开）
}
```

### 🔗 别名链

别名可以引用另一个别名，编译期递归展开：

```leno
alias A = int
alias B = A            // B → A → int
func add(A x, B y):B { return x + y }
add(3, 4)              // 7
```

### 📦 嵌套与组合

```leno
alias IntList  = Array[int]
alias IntMatrix = Array[IntList]              // Array[Array[int]]
alias UserInfo  = Dict[string, string]
alias UserDB    = Dict[string, UserInfo]      // 深层组合
```

### 🏠 局部别名

在函数体内定义别名，作用域限于该函数：

```leno
func test() {
    alias Words = Array[string]
    Words w = ["hello", "world"]
    print(w)     // ["hello", "world"]
}
```

### 🤝 泛型配合

别名可与泛型函数无缝使用：

```leno
alias IntArr = Array[int]

func map[T, U](Array[T] arr, func(T):U fn):Array[U] { ... }
func double(int x):int { return x * 2 }

IntArr nums = [1, 2, 3]
var doubled = map(nums, double)  // 别名完全等价于 Array[int]
```

### ⚠️ 注意事项

1. **纯编译期替换**：`type()` 返回展开后的实际类型（`Array[int]`），而非别名
2. **别名可嵌套**：`alias A = Array[int]; alias B = Array[A]` 等价于 `Array[Array[int]]`
3. **支持任意类型**：基本类型、数组、字典、函数类型均可作为别名目标
4. **不支持泛型别名**：`alias Box = Array[T]` 不合法（T 未定义）
5. **同名覆盖**：后定义的同名别名会覆盖前者

## 14. 总结

- **变量**：`var` 声明，编译器推断
- **参数**：写具体类型，编译器检查
- **返回**：显式声明，调用者安心
- **any**：灵活但需显式转换，小心使用
- **类型守卫**：`is` 关键字收窄类型，只在 if 块内有效；支持变量守卫和 Dict 字段守卫
- **安全转型**：`as` 关键字安全类型检查，匹配返回原值，不匹配返回 null；`int` ↔ `float` 自动数值转换
- **switch 类型匹配**：`case is Type` 按类型分支，比 `if-is` 链更清晰，支持值+类型混合匹配
- **函数类型**：可以作为值传递、参数、返回值；相同类型完全匹配，具体类型可赋值给通用类型

> **不确定时用** **`var`，确定时写类型！**
