# 布局配方（LenoSDL3）

> 这不是 API 手册 —— 参数表从源码注释就能查到，而且会跟着代码变。
> 这里回答的是**"我想要 X 效果，该用哪几个组合"**，以及**哪些写法一定会翻车**。
>
> 配方全部来自实际项目（Aria 播放器）里跑通的代码；反模式全部是真实踩过的。

## 一、从零开一个窗口

最小的可运行骨架：

```leno
import "SDL3" as SDL3
use SDL3.(Event, Renderer, Window, VBox, HBox, Label)

func run() {
    SDL3.ttfInit()                       // 用文字就必须先初始化字体（忘了直接崩）
    SDL3.setTheme(SDL3.darkTheme())

    Window w = SDL3.createWindow({title: "Demo", w: 800, h: 600})
    if not w.ok { SDL3.ttfQuit(); return }   // ⚠ 必须判：创建失败时后面全崩

    // ① 建根容器（贴满窗口的竖排）
    VBox root = SDL3.createVBox({x: 0, y: 0, w: 800, h: 600,
                                 pad_x: 16, pad_y: 12, spacing: 8})
    w.add(root)

    // ② 往里塞控件
    root.add(SDL3.createLabel({text: "你好", font_size: 20}),
             {grow: 0, shrink: 0, basis: 32, align: 3})

    // ③ 跑主循环：第一参数收事件（返回 false = 退出），第二参数每帧画背景
    w.run(func(Event ev): bool {
              if ev.isQuit() or ev.isWindowClose() { return false }
              return true
          },
          func(Renderer r) { /* 画背景渐变等 */ })

    SDL3.ttfQuit()
}
```

### 关键点

| 事情 | 怎么做 | 坑 |
|---|---|---|
| 初始化 | `SDL3.ttfInit()` / 退出时 `ttfQuit()` | 漏了就崩溃，不是报错 |
| 建窗口 | `createWindow({title, w, h})` | 返回的 `w.ok` **必须判** |
| 加控件 | `w.add(控件)` | 加进去就贴窗口绝对坐标 |
| 主循环 | `w.run(onEvent, onRender)` | `onEvent` 返回 `false` 才退出 |
| 定时器 | `w.addTimer(毫秒, func() {...})` | 周期任务（比如每 200ms 轮询）放这里 |
| 每帧逻辑 | 同上，或用 `onRender` 回调 | 逐帧重算的东西别放 `onEvent` |

### ⚠ 一个必须知道的事

`w.run` 的**事件钩子只收到「窗口级事件」**（resize / quit / close / focus），
**收不到鼠标事件** —— 鼠标是框架派发给各个控件的。

想在应用层监听"点了哪"：

- 控件上挂 `on_click`（正路）
- 或者用 `set_modal` / `set_click_outside`（见 §五）

```leno
// 反例：这样写永远不触发
w.run(func(Event ev): bool {
          if ev.isMouseButtonDown() { print("never") }   // ✗ 收不到
          return true
      }, ...)
```

## 二、先选容器（30 秒决策）

| 你要的效果 | 用哪个 | 备注 |
|---|---|---|
| 竖着一列 | `VBox` | 最常用 |
| 横着一行 | `HBox` | 次常用 |
| 叠在一起 / 绝对定位 | `AnchorBox` | 用 `{left, top, w, h}` 定位 |
| 等宽网格（海报墙） | `GridLayout` | 支持运行时改列数（`set_cols`） |
| 内容超出要滚 | `ScrollView` + 一个 `VBox` | **内容高必须自己给**，见 §四-6 |
| 一块带背景/圆角/裁剪的区域 | `Panel` | `setLayout(vbox)` 装内容；要内边距用 `setLayoutPadded(vbox, pad)` |
| 可点的整块卡片 | `Card` | `content_click_through: true` 让内容不吞点击 |

**经验**：先想"主方向"，主方向用 `HBox`/`VBox`，不规则的叠层再套 `AnchorBox`。
不要一上来就 `AnchorBox` 手摆坐标 —— 窗口一缩放全乱。

## 三、五个键的语义（一张表看完）

| 键 | 作用方向 | 语义 | 常见误用 |
|---|---|---|---|
| `grow` | **主轴** | 吃掉**剩余空间**，`>0` 时还会顺带撑满交叉轴 | 以为它能"让内容靠左" |
| `shrink` | 主轴 | 空间不够时压缩自己（`1` = 允许） | 不加它，长文字会把容器撑破 |
| `basis` | 主轴 | 主轴方向的基础尺寸（`VBox` 里是高） | 和 `w`/`h` 混着写，不知道谁生效 |
| `align` | **交叉轴** | `0` 起始 / `1` 居中 / `2` 末端 / `3` 撑满 | 把 `2` 当居中（其实是靠右） |
| `justify` | 主轴 | 容器自己的对齐（`1` = 居中） | 和 `align` 搞混 |

**一句话记法**：

```
grow   = 沿主方向抢空间（会把兄弟顶开）
align  = 垂直于主方向摆位置（3 = 撑满）
```

`align: 3` 会**覆盖**子控件自己声明的 `w`/`h`（源码里就是 `cw = innerW`）。
所以"我明明写了 w: 300 怎么没用"—— 不是没生效，是被 `align: 3` 或 `grow` 覆盖了。

## 四、配方

### 1. 行内「文字 + 紧跟的徽标」

文字**超长要省略**，徽标紧贴其后。

```leno
HBox row = createHBox({w: 120, h: 21, spacing: 6});     // w 只是占位，外层会撑开
// ⚠ 关键：grow: 0 + shrink: 1
row.add(ui.lblFit(title, 14, color, true), {grow: 0, shrink: 1, align: 3});
row.add(qualityTag(...),                    {grow: 0, shrink: 0, align: 1});
```

- `grow: 1` → 文字吃满整行，徽标被顶到行尾（看起来像浮在中间）
- `shrink: 1` → 文字超长时缩，`lblFit` 的省略号照常生效

**这是 flex 的语义，不是框架问题**：`grow` 抢剩余空间是它的本职。

### 2. 整行铺满、卡片等宽

```leno
int cols = cardSize.cols_of(avail);       // 按可用宽度算能放几张
int cw   = cardSize.card_cw(avail);       // 卡宽 = (avail - 间距) / cols
HBox row = createHBox({w: avail, h: h_of(cw), spacing: CELL_GAP, clip: true});
for 0 : cols - 1 to i {
    row.add(cards.wide_card(items[k + i], cw, false, cardSize, hooks),
            {grow: 0, shrink: 0, basis: cw, align: 1});     // 卡宽固定，别 grow
}
```

- 卡宽**由列数推**，不要让卡片 `grow` —— 否则最后一行只有 1 张时会被拉成整行宽
- 不足一行时补空 `Label`（`{grow: 1, shrink: 1}`）占位

### 3. 左右两端对齐

```leno
HBox head = createHBox({w: 800, h: 34, spacing: 10});
head.add(title,            {grow: 0, shrink: 0, align: 1});   // 左
head.add(createLabel({}),  {grow: 1, shrink: 1, align: 1});   // 中间海绵
head.add(button,           {grow: 0, shrink: 0, align: 1});   // 右
```

中间的"空 Label 吃剩余空间"是标准做法，比算宽度稳。

### 4. 元素叠在图上（角标 / 播放标记）

```leno
AnchorBox cov = createAnchorBox({w: 100, h: 100});
cov.add(封面ImageView, {left: 0, top: 0, w: 100, h: 100});      // 底层
cov.add(黑圆Panel,     {left: 28, top: 28, w: 44, h: 44});      // 中层
cov.add(播放三角,      {left: 37, top: 37, w: 26, h: 26});      // 顶层
```

- `AnchorBox` 的子项都用 `{left, top, w, h}` **绝对定位**，尺寸不会跟着内容变
- 想整体显隐：外层用 `Panel`（`AnchorBox` 早期版本没有 `set_visible`，
  后来补了 —— 但现在仍推荐 `Panel`，因为它自带圆角底色，能省一层 `Canvas`）

### 5. 居中 / 靠右

```leno
{v: 控件, align: 1}     // 交叉轴上居中（VBox 里 = 水平居中）
{v: 控件, align: 2}     // 交叉轴上靠末端（VBox 里 = 靠右）
{v: 控件, align: 3}     // 撑满交叉轴
```

**别把 `align: 2` 当居中** —— 那是靠右，我之前就搞错过。

文字本身还想居中（而非控件框居中），要包一层：

```leno
HBox mid = createHBox({w: 48, h: 22, justify: 1});    // justify:1 = 主轴居中
mid.add(label, {grow: 0, shrink: 0, align: 1});
```

### 6. 滚动区里放可变高内容

```leno
VBox inner = createVBox({w: w, h: 420, spacing: 12});
// ... 往 inner 里塞内容 ...
ScrollView sv = createScrollView({w: w, h: 380, smooth: true, bar_w: 6.0,
                                  bar_color: #C9A9B880});
sv.set_content(inner);
```

- `ScrollView` 的**内容高是自然高**，所以里面的表格即使 `grow: 1` 也只撑到自然高
- 内容超高才出现滚动条；`content_h` 没给时框架自己测
- 想在滚动区里做"整页撑满的表格" → **别用 ScrollView**，改用独立容器 + `win.add`

**读滚动状态**（"滚到底加载更多"）：

```leno
sv.get_scroll_y()          // 当前偏移
sv.get_content_h()         // 内容总高
sv.near_bottom(200.0)      // 距底 200 以内 ⇒ true（内容比视口矮时恒 false）
```

### 7. 弹层贴在按钮上方

**坐标必须在打开时现算**，不能建面板时写死：

```leno
float bx = btn.get_x() + btn.get_w() / 2.0 - panel.get_w() / 2.0;   // 按钮水平中心
float by = btn.get_y() - panel.get_h() - 8.0;                       // 按钮上沿再往上
panel.set_pos(bx, by);
```

写死常量的话，窗口一缩放浮层就飘在中间。

配套两件事：

```leno
win.set_modal(panel, panel.get_x(), panel.get_y(), panel.get_w(), panel.get_h());
// 落在浮层矩形内的事件只派发给它 ⇒ 防穿透

win.set_click_outside(panel.get_x(), panel.get_y(), panel.get_w(), panel.get_h(),
                      func() { close_panel() });
// 点外面 ⇒ 自动收起
```

窗口尺寸变化时记得收起浮层（尺寸变了位置就不对了）：

```leno
if ev.isWindowResized() { close_panel(); win.clear_modal(); win.clear_click_outside() }
```

### 8. 竖向滑块（音量条）

**别交给 `VBox` 的 `grow` 撑**：滑块圆点直径按 `w * 0.45` 算，被撑到容器宽就变成一根温度计。

```leno
AnchorBox col = createAnchorBox({w: 40, h: 176});
col.add(数字,  {left: 0,  top: 0,  w: 40, h: 22});
col.add(滑块,  {left: 14, top: 28, w: 12, h: 146});   // 显式给宽
```

滑块自己也要 `show_value: false`，否则它自带的数值会和外面的百分比挤在一起。

## 五、反模式（每条都真实翻过车）

| 写法 | 后果 | 正确做法 |
|---|---|---|
| 文字用 `grow: 1`，后面还想跟徽标 | 徽标被顶到行尾 | `grow: 0, shrink: 1` |
| 把 `w` 写成比真实列宽更大的值 | 里面的 HBox 按那个宽排，后续元素位置错 | 写小值让外层撑开 |
| 竖直 `Slider` 交给 `VBox` 的 `grow` | 变成温度计 | `AnchorBox` + 显式 `w` |
| 滚动区无限加载、不做虚拟化 | 控件数线性涨，内存一直爬 | 行槽 + 只填可见区（见 §六） |
| 用空 `Label` 当整行点击区 | 命中区常常是空的，点了没反应 | 用 `Card` + `content_click_through` |
| 整行 `Button` 想装"封面 + 两行字" | 只能一行字 | 同上，用 `Card` |
| 弹层坐标建面板时写死 | 窗口缩放后飘在中间 | 打开时现算（§四-7） |
| 在 `w.run` 的钩子里监听鼠标 | 永远收不到 | 控件 `on_click` / `set_click_outside` |
| 重建容器时只 `clear()` 不 `dispose()` | 纹理/字体泄漏，内存只涨不降 | `reset()`（= dispose + clear） |
| 模块级变量写 `var x = []` | 推断成 `Array[any]`，元素上调方法编译不过 | `Array[VBox] x = []` 显式写类型 |

## 六、大数据量列表：行槽 + 虚拟滚动

固定行高的网格/列表，卡片多了（几百张）不要一次全建：

```leno
// ① 先铺**空行槽**（每行 1 个 VBox，很轻）
Array[VBox] rows = []
for 0 : totalRows - 1 to r {
    VBox slot = createVBox({w: w, h: rowH, spacing: 0});
    container.add(slot, {grow: 0, shrink: 0, basis: rowH, align: 3});
    rows.add(slot);
    rowState.add(-1);                 // -1 = 空
}

// ② 每帧按滚动位置填/收
int first = _int((scrollY - 160.0) / rowH);            // 上留 1 行余量
int last  = _int((scrollY + viewH + 160.0) / rowH);    // 下留 1 行
for 0 : n - 1 to r {
    if need and rowState[r] < 0 { fill_row(r) }
    else if not need and rowState[r] >= 0 {
        rows[r].reset();               // dispose + clear
        rowState[r] = -1;
    }
}
```

实测：180 个卡片从 248MB 降到 150MB，且页数不再需要封顶。

**要点**：
- 空槽本身很轻（1 个控件），所以"铺 30 个空槽"完全没问题
- 上下各留一行余量，快速拖动才不会看到空白
- `reset()` 而不是 `clear()` —— 前者会 release 纹理

## 七、还有几条零碎的

```leno
// 控件通用（现在所有 impl Widget 的控件都有）
w.set_visible(false)      // 显隐
w.set_enabled(false)      // 禁用（不吃事件）
w.get_x() / get_y() / get_w() / get_h()
w.is_hover()              // 语义看控件：容器 = 鼠标在矩形内；
                          // 表格/列表 = 「有某行被悬停」（看各自的注释）

// 颜色
#RRGGBBAA                 // 8 位，Alpha 在最后
```

**样式统一**：颜色、字号散落在各页面里时会越来越乱。
Aria 的做法是每个页面模块自带一份常量（`const Color TXT = #35262BFF`），
等稳定了再统一收进一个 `theme` 模块 —— 不要中途一次性改几百处引用。
