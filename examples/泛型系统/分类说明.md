# 泛型系统测试 / 示例 分类说明

本目录下的泛型相关 `.leno` 文件此前全部平铺在一层，缺乏分类，难以查找与维护。
现按"用途维度"拆分到子目录，并把被多个用例复用的**模块 fixture** 统一收拢到 `模块/`。

## 目录结构

```
泛型系统/
├── 模块/                # 被复用的泛型模块定义（fixture），需 export 才能被外部 import
├── 基础类型系统/        # 基础泛型类型、Array/Dict、type() 显示验证
├── 泛型函数/            # 泛型函数、多类型参数、map/filter 等
├── 泛型结构体/          # 泛型 struct 定义/嵌套/默认值/方法调用
├── 泛型接口与约束/      # face、约束（Comparable 等）、泛型 face 参数与 impl
├── 跨模块泛型/          # 跨文件 import 泛型 struct/函数/face 的交互用例
├── 示例/                # 完整可运行示例：栈、链表、Result、函数式
├── 边界与错误/          # 边界情况、编译期错误复刻（repro）、错误提示验证
├── 集合运算/            # 集合交并差、对称差、笛卡尔积的泛型实现
└── 分类说明.md          # 本文件
```

## 导入路径约定（重要）

- Leno 的 `import "路径"` 相对于**导入文件自身所在目录**解析，支持子目录与 `../` 上级路径。
- 所有分类目录都是 `泛型系统/` 的直接子目录；模块统一放在 `模块/`。
- 因此任意分类目录下的用例导入模块时，统一写作：
  ```leno
  import "../模块/generic_module2.leno" as gm
  ```
- 模块对外可见的符号必须用 `export` 修饰（struct / func），否则导入方报"模块中没有方法"。
